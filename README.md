# Software Construction and Development — Assignment 2

This repository is the shared GitHub workspace for the Software Construction and Development Assignment 2.

## Assignment scope

The assignment asks the group to:
- collect and analyze responses from at least two software-development respondents;
- identify development practices and at least three common challenges;
- design and implement a small Java prototype demonstrating OOP, modularity, exception handling, a design principle or pattern, and test cases;
- collaborate through GitHub using individual contributions, feature branches, commits, and integration.

## Team workflow

1. Keep `main` as the stable integrated branch.
2. Create a separate branch for each real task, for example `feature/student-management` or `docs/survey-analysis`.
3. Commit focused changes with clear messages.
4. Open a pull request to review and integrate a feature branch.
5. Record each member's real work in `docs/TEAM_CONTRIBUTIONS_TEMPLATE.md`.

## Important

This repository currently provides the collaboration setup and documentation. Add the group's actual Java prototype, survey responses, diagrams, and screenshots before submission. Do not invent respondent answers or attribute work to a group member who did not make it.
